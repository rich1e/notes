# NDS 烧录卡（R4 / DSTWO）

## 所需材料

- NDS/NDSL/3DS 掌机
- R4iSDHC 烧录卡（金手指处印有官网地址）
- TF（MicroSD）内存卡 + 读卡器
- 内核固件

## 内核下载与安装

1. 访问 [http://cn.r4isdhc.com](http://cn.r4isdhc.com) 下载对应版本内核
2. 解压内核文件，将所有文件转移到 TF 卡根目录

**TF 卡格式化**：
- 容量 ≤32GB：FAT32 格式（直接用系统格式化）
- 容量 >64GB：使用 DiskGenius 等专业工具格式化为 FAT32

## ROM 文件管理

- 游戏 ROM 放在 TF 卡根目录或一级子文件夹中
- **注意**：不能嵌套两层以上文件夹，否则内核检测不到游戏
- 进入游戏：选中 ROM → 按 A 键或点击图标

## 操作快捷键（内核界面）

| 按键 | 功能 |
|------|------|
| A | 打开文件夹 / 启动游戏 / 播放媒体 |
| B | 退出 / 返回上一级 |
| L | 调节屏幕亮度 |
| R | 退出到内核界面 |
| Select | 浏览近期打开的文件 |
| Start | 打开设置菜单（记事本、系统设置、壁纸等） |

## 金手指与存档

进入游戏后按 B 键可以：
- 选择金手指（Cheat Code）
- 管理存档
- 开启即时存档功能

## 多媒体功能（moonmemo 播放器）

播放器支持：MP3 音乐、DPG 格式视频、图片浏览、TXT 文本阅读、记事本

使用方式：
- 打开播放器 → 选中对应格式文件 → 按 A

## R4 卡版本对比

> 来源：cnblogs/mcxw 综合玩家经验帖（2022）

**结论**：r4hk = dsone > r4com > r4cn

| 版本 | 识别特征 | 内核 | 兼容性 | 现状 |
|------|----------|------|--------|------|
| **r4hk** | 烧录卡背面印 r4isdhc **.hk** 地址；插入后图标显示海绵宝宝 | 最优秀，可刷 bl2ck 内核 | 最佳 | **2017/2018 已停产，之后全是假卡**，价格 40+ |
| **dsone** | 另一公司产品；分支少、辨识简单 | 独立内核 | 与 r4hk 同级 | 真品同样稀缺 |
| **r4com** | 背面印 r4.com 地址；图标显示炸弹人 | 标准内核 | 比 hk 略差 | 量大便宜，颜色多样但本质无差别；炸弹人图标含倒计时，需定期刷最新固件 |
| **r4cn** | 一般是"两把剑"图标 | 支持 wood 内核，被部分商家称为"新 hk 卡" | 兼容性还行，功能略差，**不支持即时存档** | 山寨卡 |

**R4 演进史**：最早只有 [r4.com](http://r4.com/) 一家；2013 年经销商与开发组内部分裂，部分人出走成立 hk 版本。

**金银铜卡关系**：金银铜卡实际上是同一马甲的不同版本（寨厂复用），选购时务必看背面网址识别。

**DSTWO 体验**：最好的烧录卡是 DSTWO，比一般烧录卡贵，因为上面有缓存，模拟 GBA 不卡。3DSLL 上插 DSTWO 是稳定方案。

**红蓝破解卡**：当年 3DS 时代有红蓝破解卡。红卡同上一台机器卖掉；蓝卡与烧录卡接近，刷一个内核即可当烧录卡用，目前插在 NDSI 上。

**TF 卡选品**：除烧录卡外，TF 卡本身也很重要。尽量选大品牌（推荐 Sandisk，多年使用未坏过），NDS 游戏 16G 足够。

## R4iSDHC 常见 FAQ（13 条）

来源：cnblogs/mcxw 整理自官方资料

### 1. TF 卡碎片问题

在使用 R4 卡之前，先用官方专用工具 SDFormatter 格式化 TF 卡。**避免或解决以下问题**：
1. RTS 启动后游戏白屏
2. RTS 启动后游戏死机
3. 运行游戏速度慢
4. 加载内核时白屏

操作要点：选择「覆盖格式化」与「开启」选项，保存后等待完成。
工具下载：Formatter 3.1（[百度网盘](https://pan.baidu.com/s/1dDrFim9)）。

### 2. 显示文件名太长的讯息

NDS 文档名（含路径）**不能超过 80 个字节**。改短文件名即可。

### 3. 更改 R4i 语言设定

通过内核界面即时更改：上屏右上角第三个图标，按 `X/B` 进入语言更改选项。

### 4. 游戏启动不了

可能是游戏带反烧录卡程序。下载最新版 R4i 内核（包含对应游戏破解），如仍不行可自行下载游戏破解补丁。最差情况邮件报告 R4i 技术支持。

### 5. 更换 R4i 皮肤

到 [www.r4isdhc.com](http://www.r4isdhc.com) 下载皮肤或参考「中文内核使用说明下载」自行制作。**R4i v1.08b+ 支持即时更换皮肤，最多支持 8 款**。

### 6. 游戏数量庞大时快速选择

内核游戏选择界面上，**下屏右下角的放大/缩小图标**进入快速游戏切换模式。也可用左右按键翻页（每页显示 4 个游戏）。

### 7. 从游戏画面回到内核界面

**同时按 `X + Y + B + A + L + R` 键**。

### 8. 游戏金手指

1. 选择要启动金手指的游戏
2. 按 `B` 切到金手指界面
3. 打勾要使用的金手指项目
4. 打开金手指启动按键
5. 回游戏界面进入游戏
6. 要存储设置记得按存档键

开启金手指后游戏图标旁的小金手指图标会变金色。**经常到官网更新 `usrcheat.dat` 金手指资料库以支持新游戏**。

### 9. 从 Moonshell 返回内核

Moonshell 界面按 `Start` 键进入选择菜单 → 选择「返回到烧录卡内核界面」。

### 10. 卡死在 "MENU"

SD/TF 卡上没安装 R4i 内核。到 [www.r4isdhc.com](http://www.r4isdhc.com) 下载并按指示安装。

### 11. 卡死在 "NO CARD"

找不到 SD/TF 卡。**确认 SD 卡是否正确插入**；也可能 SD 卡本身损坏。

### 12. 卡死在 "LOADING"

确认使用 [www.r4isdhc.com](http://www.r4isdhc.com) 官方内核（仅适用于 R4i-SDHC 与 R4-SDHC 烧录卡）；其它卡型不支持。

### 13. 卡带真伪判断

- 真 hk 卡（2017/2018 前生产）背面网址以 `.hk` 结尾，内核最优
- 2017/2018 之后**所有新卡基本都是假卡**
- 假卡内核质量差，兼容性弱，长期使用风险高

## R4iSDHC 用户体验（来自 jixun 评测）

来源：[浅谈 R4iSDHC 用户体验](https://jixun.uk/posts/2016/r4isdhc-simple-review/)

### 系统内核操作痛点

- **文件浏览器只能递归一层**：所有根目录和子目录一层的 `.nds` 文件会被列出，更深一层被无视。若用两层以上目录归类游戏，列表里看不到。
- **Per-ROM 设定用 X / B 上下切换**：反人类的输入映射，jixun 抱怨"心都累"。
- **三入口菜单**：游戏 / 多媒体 / 设定，启动时选择。

### 兼容性与游戏表现

- **Game Boy Advance 汉化版兼容性好**：例如《游戏王 GX：灵魂召唤者》汉化在两个 Wood 内核的 R4 山寨卡上白屏，R4iSDHC 可正常运行（屏幕底部有小毛病）。
- **无法模拟 NDS 主机语言**：汉化版游戏要求日版 NDS，但欧版 3DS 跑出来仍是英文，无法切到日语机区显示汉化。
- **启动速度偏慢**：尤其是首次启动某游戏，需要建立存档约半分钟。

### 即时存档（RTS）缺陷

R4iSDHC 的 RTS 功能菜单画着四个存档位，实际上**只能 A、B 两个**：菜单里的 `SAVE C & D` 永远是禁用状态；A 和 B 写一次之后再按下即时存档快捷键**直接死机**。

#### 强制开启四个存档位的 Hex Hack

1. 用 HxD 或其他 Hex 编辑器打开 `SD:/R4iMenu/R4i.sav`
2. 搜索字节 `23 23`（通常在卡带 ID 附近）
3. 把附近的 `23` 全部替换为 `AB`

但此 Hack 有可能进一步加剧不稳定，仅作研究用。

### jixun 的结论

> "想要即时存档和超强的 Rom 兼容性，还是用 DsTwo 吧，别想省钱。"

R4iSDHC 内核与 DSTwo 相比像是"抄来抄去抄出四不像"——还不如拿 Wood 内核 + 单独维护兼容性补丁。
