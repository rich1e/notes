# 任天狗狗（Nintendo Wansui）

任天狗狗是 [[entities/ique-dsi|iQue DSi]] 内置的虚拟宠物游戏（Nintendo/iQue 出品），可以用手写笔和麦克风训练小狗，与它们进行互动娱乐。

## 核心玩法

- 最多可以养 **5 只小狗**
- 多种**物品**可供你和小狗玩耍或使用
- 使用**手写笔**（触摸屏操作）和**麦克风**（语音指令）互动

## 游戏主页界面

| 界面元素 | 功能 |
|---|---|
| 小狗图标 | 点触后上屏幕放大显示该只小狗，再次点触缩小 |
| 物品列表 | 点触物品图标，可使用所拥有的物品 |
| 点触 | 对小狗进行互动 |
| 训练 | 训练小狗的区域 |
| 小狗状态 | 显示当前小狗的状态 |
| 呼唤 | 点触呼唤小狗的名字 |
| 保存 | 保存游戏进度 |

## 注意事项

- 如果因软件管理画面中删除等原因删除了《任天狗狗》，可以从 iQue DSi 商店免费再次获取
- 如果删除时游戏记录将被彻底删除且**无法恢复**，请注意
