# VoltAgent

> 维护 awesome-design-md 仓库与 getdesign.md 目录服务的开源组织；同名 AI agent 框架（voltagent）的出品方。

| 商业模式 | 商业服务（私人订制）+ LaunchKit banner 广告（README 中显式招赞助） |

## 与 awesome-design-md 的关系

README "AI Design + Build Ecosystem Tools" 章节显示 VoltAgent 是 awesome-design-md 的**主要运营方 + 商业受益方**：
- 维护仓库内容
- 运营 getdesign.md 目录服务
- 通过私人订制与 banner 广告变现
- VoltAgent 自己的 DESIGN.md（`getdesign.md/voltagent/design-md`）也在收录列表里——自我收录^[inferred]

## 在 vault 中的位置

VoltAgent 是 [[entities/awesome-design-md]] 与 [[sources/getdesign-md-marketplace]] 的**共同上游**——理解这两个页面时需要看到这个统一运营方。它**不是** Google 官方组织，所以 awesome-design-md 仓库的设计 tokens 是 "inspired interpretation" 而非官方规范——这一身份定位对评估 IP 与准确性都很关键。
