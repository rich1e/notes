# Sebastian Raschka

## 简介

Sebastian Raschka 是一位专注 LLM 教育的 AI 研究者与作者。著有多本技术书，最新是 Manning 2024 出版的《Build a Large Language Model (From Scratch)》。同时维护同名 GitHub 仓库（rasbt/LLMs-from-scratch），持续更新。

## 主要著作（provenance: extracted）

- **Build a Large Language Model (From Scratch)**（Manning, 2024, ISBN 978-1633437166）
- **Machine Learning with PyTorch and Scikit-Learn**
- **Python Machine Learning**（早期经典）

## 主要项目

- **rasbt/LLMs-from-scratch** — 见 sebastian-raschka-llms-from-scratch-book
- **rasbt/LLMs-from-scratch-reasoning**（姊妹仓库）—— GRPO/RLVR、verifier、inference scaling
- **rasbt/stat453-deep-learning** — 早期深度学习课程

## 学术经历

- 曾在 Stanford CS336 作为客座讲师分享 LLM 训练经验
- 个人博客：[sebastianraschka.com](https://sebastianraschka.com/)

## 教学风格（provenance: inferred）

- 与 Karpathy 对照：
  - **Karpathy**：手写 + 直觉，**隐藏库调用**
  - **Raschka**：PyTorch + 工程化，**透明实现但不要求手写**
- "普通笔记本可跑"是该书最重要的实用卖点——不会被硬件门槛劝退
- 仓库**持续维护**，不断加入新架构（Llama 3.2、Qwen3、Gemma 3 等）——是少数"买了书能持续收到更新"的资源

## 影响力

- 与 Karpathy 并列为 LLM 学习**事实标准**的两大作者
- 中文社区也广为流传——知乎/B 站有大量笔记和搬运
