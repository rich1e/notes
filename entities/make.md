# Make (原 Integromat)

> Make(前身 Integromat)是纯云工作流自动化 SaaS,以**可视化画布(scenario)** 表达力最强著称,支持复杂分支、迭代、数据聚合,介于 Zapier 的极简与 n8n 的代码能力之间。

## 定位

| 维度 | Make |
|------|------|
| 部署 | 仅云(SaaS),不可自托管 |
| 可视化 | 业界最强的 scenario 画布 |
| 复杂逻辑 | 强(路由/迭代/聚合器) |
| 目标用户 | 半技术用户,视觉化建流 |
| 数据主权 | 无——数据经其云 |

## 在竞争格局中

在 [[concepts/workflow-automation-platform]] 里,Make 代表"可视化编排最强但纯云"一极,对照 [[entities/n8n]] 的自托管开源与 [[entities/zapier]] 的极简易用。
