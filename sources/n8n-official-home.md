# n8n.io 官方主页

> 一手来源：[n8n.io](https://n8n.io/)

## 官方定位

n8n 是 **AI workflow automation platform**——"build visually, go deep with code, connect to anything"。核心叙事三件套：

1. **可视化 + 代码同框**——其他工具要不全可视化，要不就纯代码；n8n 把两种范式合一
2. **AI agents 与 RAG 原生支持**——canvas 上能看到推理路径、可追溯
3. **部署灵活**——用户基础设施或 n8n 托管都可

## 用户画像

"Technical teams"——IT Ops、Sec Ops、Dev Ops、销售。典型场景：

- 员工 onboarding 自动化
- 安全工单增富（enrichment）
- natural-language → API（NL2API）
- 客户洞察生成
