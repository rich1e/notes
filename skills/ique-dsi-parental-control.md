# iQue DSi 亲子管理设置指南

[[entities/ique-dsi|iQue DSi]] 亲子管理功能由监护人实施，可限制儿童使用或购买部分内容。每台主机只能进行一个亲子管理设置，以家中年龄最小的孩子为标准设置。

## 可限制的内容

| 可限制功能 | 说明 |
|---|---|
| **[[skills/pictochat|PictoChat]]（涂鸦聊天）** | 可限制使用 |
| **iQue DS 下载游戏** | 可限制使用 |
| **iQue DSi 商店** | 可限制 iQue DSi 点数的使用（无法购买） |
| **相片的交换** | 可限制通过无线连接交换相片 |
| **其他** | 可限制部分分用户制作的内容的收发 |

## 设置步骤

进入路径：主机设置 → 设置3 → **亲子管理**

### 第一次设置

1. 阅读画面上的说明，操作
2. 点触「是」

3. **输入4位数的验证密码**（需输入2次确认）
   > ⚠️ 验证密码非常重要，需要解除或更改设置时必须使用，请务必牢记。

4. **选择秘密问题**（点触 ▲▼），点触「确定」

5. **输入至少3个文字作为秘密问题的答案**，点触「确定」
   > ⚠️ 秘密问题的答案非常重要，忘记验证密码时需用来找回，请务必牢记答案。

6. 之后根据画面指示，对需要限制的软件等进行设置，点触「确定」

---

## 忘记验证密码的处理方法

### 方案 A：记得秘密问题的答案

1. 在验证密码输入画面点触「我忘了」
2. 输入秘密问题的答案
3. 即可进入亲子管理的设置画面

### 方案 B：秘密问题的答案也忘了

1. 在验证密码输入画面点触「我忘了」
2. 在秘密问题答案输入画面再次点触「我忘了」
3. 显示「咨询号码」
4. **记录咨询号码，联系神游客户服务中心**，同时告知设置日期（画面上显示）
5. 神游客服会发送一个「万能密码」
6. 输入万能密码，点触「确定」即可解锁

---

## 注意事项

- 每台主机只有一个亲子管理设置
- 设置基准应为家中年龄最小的孩子
- 使用 iQue DSi 商店时，需要先在 iQue DSi 上进行互联网设置，同意协议方可进行
- 面向中国国内发售的点卡，只能用于面向中国国内发售的 iQue DSi 主机
- 点数超过10000点时，无法再次充值
- 无法分次充值点卡里的点数
