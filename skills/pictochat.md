# PictoChat（涂鸦聊天）操作指南

[[entities/ique-dsi|iQue DSi]] 内置 PictoChat，可在主机好友间接收或发送绘画和文字，尽享合适的乐趣。

- 每个聊天室最多可容纳 **16 人**
- 也可以在中途加入聊天
- 也可以与 iQue DS / iQue DS Lite 主机进行 PictoChat（但运行有所不同）

## 启动步骤

1. 从 iQue DSi 菜单点触 PictoChat 图标
2. 起始画面显示聊天室选择画面（聊天室A、B、C、D）
3. 左边的数字代表已加入该聊天室的人数
4. 点触「加入」即可进入（若人数达到16人，不能再加入）

## 界面说明

### 上屏幕

- **信号强度图标**：当前无线信号
- **接收信息一览**：所有聊天记录
- **当前加入的聊天室**名称

### 下屏幕

| 区域 | 功能 |
|---|---|
| 聊天成员列表 | 点触可查看签名 |
| 退出聊天室按钮 | 退出当前聊天室 |
| 信息输入区域 | 绘图和文字输入区域 |
| 发送信息按钮 | 发送当前信息 |
| 删除信息按钮 | 删除当前输入内容 |
| 工具列 | 画笔/橡皮/尺寸切换 |

### 工具列

| 工具 | 功能 |
|---|---|
| 画笔 | 绘图或写字，每次点触切换颜色和彩虹画笔（新功能！） |
| 橡皮 | 擦除画图或文字 |
| 尺寸切换 | 切换画笔或橡皮的尺寸 |

## 键盘输入模式

触摸下屏幕键盘区域可输入文字，也可将文字滑动到信息输入部分自由放置。

### 字母数字键盘

| 功能 | 按键 |
|---|---|
| 切换大写/小写 | 大写固定键 |
| 删除最后输入文字 | 右上方删除键 |
| 输入空格 | 空格键 |

### 平假名·片假名键盘

- 切换平假名/片假名
- 在输入文字后加上「゛」或「゜」浊音符
- 将输入的文字切换为小文字

### 输入模式切换

| 切换 | 内容 |
|---|---|
| 字母数字 | 英文+数字 |
| A 欧洲文字及特殊符号 | 欧洲字符+特殊符号 |
| 日文平假名/片假名 | 日文假名 |
| 符号 | 符号 |
| 图形符号 | 图形符号 |

## 主机按键速查

| 按键 | 功能 |
|---|---|
| 十字键 | 光标移动 |
| A | 输入文字 |
| B | 删除最后输入的文字 |
| X | 平假名/片假名键盘：变换浊音文字、半法音文字、小文字 / 字母数字键盘：变成按了 SHIFT 键或 CAPS LOCK 键后的状态 |
| Y | 键盘切换 |
| L+R 键 | 确认信息 |
| START | 发送信息 |
| SELECT（短按）| 复制当前屏幕最下方的信息 |
| SELECT（长按）| 删除信息 |
