# iQue DSi趣音 — 录音与音乐播放操作指南

[[entities/ique-dsi|iQue DSi]] 趣音应用支持两大功能：**麦克风录音**和**SD卡 AAC 音乐播放**，并提供丰富的声音变换效果。

> 趣音是学习类应用：如果与它说话或让它听到周围的声音，会学会并记住那些声音，之后甚至可能说出录下的声音。

## 启动

从 iQue DSi 菜单点触趣音图标，起始画面分两个选项：
- **玩转麦克风录制的声音**（主机内存存储）
- **玩转SD卡中的音乐**（需将音乐文件保存到 SD 卡）

## 支持的音乐格式

| 项目 | 内容 |
|---|---|
| 文件格式 | `.m4a`、`.mp4`、`.3gp`（AAC 格式） |
| 比特率 | 16 kbps ～ 320 kbps |
| 采样频率 | 32 kHz ～ 48 kHz |
| 注意 | 无法播放 MP3 格式文件 |

## 将音乐文件保存到 SD 卡

1. 使用电脑和对应软件，将音乐转换为支持的 AAC 格式，或从音乐 CD 提取数据
2. 通过电脑的 SD 卡槽或 SD 卡读卡器，将 AAC 文件转移到 SD 卡

## 麦克风录音

### 录制步骤

1. 点触选择空白数据
2. 点触「录音」
3. 点触 ● 开始录音（麦克风感应到一定程度或更大的声音时自动开始录音）
4. 录音结束后点触「确定」

- 每个数据最多可录制 **10 秒**声音
- 声音数据只能保存在主机内存，无法从 SD 卡读取

### 数据位置移动

点触想移动的数据并滑动至目标位置，相互替换位置。

## 玩转声音数据（麦克风录音）

选择已录制的声音数据，点触「玩转」后可进行：

### 播放模式

| 模式图标 | 功能 |
|---|---|
| 循环 | 循环播放当前数据 |
| 依次循环 | 依次播放全部，结束后重头 |
| 播放一次 | 播放当前选中数据，结束停止 |
| 随机 | 随机播放 |
| A-B 区域 | 只播放设置的区域（A到B点） |

### 更改播放速度和音程

拖动十字轴图标：
- X轴（左右）：播放速度（慢 ←→ 快）
- Y轴（上下）：音程（高 ↑↓ 低）

### 12种声音变换效果

| 效果 | 说明 |
|---|---|
| 鹦鹉 | 模仿各种声音 |
| 合成机 | 机械化音色 |
| 机器人 | 机器人音效 |
| 秘密 | 悄悄话音效 |
| 甲虫 | 昆虫音效 |
| 风声 | 风声效果 |
| 低音乐声 | 低沉乐器音 |
| 小鸟 | 鸟鸣音效 |
| 高音轨道 | 高亢音效 |
| 口笛 | 哨声音效 |
| 3人合唱 | 合唱音效 |
| 综合器 | 电子合成器 |

### 保存已变化的声音

1. 在声音已变化状态下点触「覆盖」
2. 确认声音
3. 点触「确定」，声音被保存（数据颜色变为录音色）

## 玩转 SD 卡中的音乐

### 选择并播放

1. 点触想听的文件夹 → 点触「打开」
   - 选择「随机」：随机播放曲目
   - 喜爱的音乐会显示「最爱10首」和「怀旧」文件夹
2. 选择音乐文件 → 点触「播放」

### SD 卡文件夹限制

- 只显示含有音乐文件的文件夹
- 最多显示 1000 个文件夹
- 同名文件夹合并显示
- 每文件夹最多显示 100 个音乐文件；总共最多 3000 个
- 不支持显示层数超过6层的文件夹

### 播放界面功能

| 功能 | 操作 |
|---|---|
| 播放/暂停 | 触摸播放按钮 |
| 上/下一首 | 对应按钮 |
| 循环/随机/A-B区域 | 更改播放模式 |
| 调节音量 | 滑动条 |
| 添加音效 | 按 L/R 键 |
| 卡拉OK模式 | 消除歌手声音，变为卡拉OK音乐 |
| 回声 | 在音乐中加入回声 |
| 自动音乐盒 | 将音乐变成钢琴音乐盒的哼唱 |
| 录音叠加 | 将已录制的声音数据在音乐中播放 |

## 设置

在趣音设置中可调整：
- **耳机**：立体声 / 单声道
- **点触音**：玩转 SD 卡音乐时，按触摸键是否发出声音
- **背光灯**：一定时间没有操作后，自动关闭背光灯
- **保存数据的初始化**：删除所有已录制声音数据、音乐文件喜爱设置、鹦鹉记住的声音
