# iQue DSi趣照 — 相机功能操作指南

[[entities/ique-dsi|iQue DSi]] 内置趣照应用，提供 **11 种趣味相机**。拍摄的相片保存到主机内存或 SD 卡（最多 3000 张）。

## 启动方式

- 从 iQue DSi 菜单点触趣照图标
- 从菜单按 `[内]` 或 `[外]` 键直接进入照相机模式

## 11 种趣味相机

| 相机名称 | 功能描述 | 页码 |
|---|---|---|
| 普通照相机 | 无特殊效果，普通拍摄 | p.10 |
| 扭曲照相机 | 滑动使画面像被拉扯一样扭曲 | p.10 |
| 涂鸦照相机 | 使用画笔和图章涂鸦，吸管工具可吸取颜色 | p.11 |
| 着色照相机 | 画面显示黑白色，点触处颜色从黑白变为原来颜色（白/黑/灰色不变） | p.11 |
| 变色照相机 | 点触处颜色随机变换为其他颜色 | p.12 |
| 镜子照相机 | 看上去像镜子，3种类型：反向镜/三角形万花筒/四边形万花筒 | p.12 |
| 乐摘照相机 | 在脸部贴上乐摘道具（帽子、眼镜、胡须等） | p.13 |
| 表情照相机 | 随心改变人脸表情（笑/生气/哭/悲伤） | p.13 |
| 脸部合成照相机 | 将两人脸部合成，可调比例（0%~100%） | p.14 |
| 相似度照相机 | 判断两人脸部相似度（百分比），两张脸同时入镜 | p.15 |
| 相框照相机 | 使用相框（挖空的相片）拍摄，可自制相框 | p.16 |

## 脸部识别注意事项

使用需要识别脸部的相机时，提高精度的要点：
- ✅ 在明亮处拍摄
- ✅ 脸部整体对到画面上
- ✅ 脸部正面对准画面
- ❌ 不要倾斜脸部
- ❌ 遮挡或露出眉毛
- ❌ 戴眼镜

## 涂鸦相机 — 吸管工具使用

1. 选择吸管
2. 点触想要吸取颜色的部分
3. 画笔颜色变为吸取的颜色

## 相框制作方法

1. 在拍摄画面点触「制作相框」
2. 选择「新拍摄的相片」或「相册里的相片」
3. 拍摄用于制作相框的相片（或从相册选）
4. 点触并挖空相片，制作相框（挖空笔/填充笔工具）
5. 点触「完成」，相框保存为相框数据
- 制作完的相框可从「更换相框」中选择使用

## 相册功能

从趣照起始画面选择「相册」后，可查看、加工、删除相片。

### 照片分类

可按贴纸（♠ ♣ ♥）分类：
- ♣ 贴纸的相片会显示在 DSi 菜单上屏幕
- 在 DSi 菜单中拍摄的相片一开始默认有 ♣ 贴纸

### 日历功能

选择「日历」，按日期查看拍摄的相片，并可写便条。

### 幻灯片

- 自动依次显示相片
- 可更改显示顺序（按序/随机）、显示方法、配乐
- 设置在下屏幕，上屏幕全屏播放

## 照片的交换、复制、删除

### 交换（主机间无线传输）

双方均需 iQue DSi 主机；发送方最多可选择3个接收方。

**流程：**
1. 发送方：点触「发送」→ 选择主机或SD卡 → 选择「相片」或「相框」→ 选择文件 → 发送
2. 接收方：点触「接收」→ 点触保存位置（主机/SD卡）→ 等待接收

**注意：** 通过无线传输的相片和相框可能被接收方或第三方再次发送；发送前注意肖像权、隐私权、著作权。

### 复制（主机与 SD 卡之间）

- 从主机复制到 SD 卡，或从 SD 卡复制到主机
- 可选：所有相片 / 按贴纸类型 / 一张张复制
- 无法复制的情况：SD卡未插入、容量不足、SD卡有300条软件/保存数据、SD卡写保护

### 删除

- 可删除主机或SD卡中的相片、相框、便条
- 删除「所有相片」和「贴纸相片」时，选中途中取消也可能有部分相片被删除

## 照片数据限制

- 只有通过 iQue DSi 主机拍摄的相片数据才能在趣照或玩转功能中显示
- 在电脑或其他设备上对 iQue DSi 主机照片进行移动、删除、编辑后，将无法在趣照中显示或玩转
- SD 卡存储时，PC 上的缩略图若未经编辑也会一并编辑
