# iQue DSi 主机设置参考

[[entities/ique-dsi|iQue DSi]] 主机设置分为四页，通过 `◀ ▶` 切换页面。

## 主机设置 1

| 选项 | 功能 |
|---|---|
| **软件管理** | 整理主机内存和 SD 卡的数据（复制/删除）。注：没有启动过 iQue DSi 商店则不显示此项目 |
| **无线连接** | 切换无线连接功能的开启/关闭。飞机上须关闭 |
| **亮度调节** | 调节画面亮度（4档）。屏幕越亮，电池持续时间越短 |

### 软件管理操作

无法复制的情况：
- SD 卡未插入
- 目标设备副余容量不足
- 想复制且无法复制的数据（如 iQue 菜单、剩余盒子为 0）
- 要复制到的主机不是之前被保存此数据的主机
- SD 卡中已存有 300 款软件或保存数据
- SD 卡处于写保护状态

### 亮度调节快捷键

在游戏中：按 `SELECT + 音量` 键可直接调节（使用 SELECT 键进行游戏时注意）。

## 主机设置 2

| 选项 | 功能 |
|---|---|
| **用户信息** | 设置用户名、签名、用户颜色（影响 iQue DSi 菜单等多处显示）、生日 |
| **日期** | 设置当前日期（部分游戏使用此设置） |
| **时间** | 设置当前时间（部分游戏使用此设置） |
| **闹钟** | 设置闹钟时间，到时屏幕变暗，闹钟响后"防睡懒觉功能"启动（5分钟后再次响，1小时后自动解除） |

### 用户信息说明

- **签名**：在 [[skills/pictochat|PictoChat]] 中被看到，可在签名里输入对聊天对方的问候语或简单的自我介绍
- **用户颜色**：选择的颜色会在 iQue DSi 菜单等各处画面中使用

## 主机设置 3

| 选项 | 功能 |
|---|---|
| **亲子管理** | 由监护人实施的使用限制功能，详见 [[skills/ique-dsi-parental-control]] |
| **触摸屏** | 校准触摸屏的偏差 |
| **麦克风测试** | 确认麦克风是否工作正常 |
| **互联网** | 设置互联网连接，详见 [[skills/ique-dsi-wifi-setup]] |

### 触摸屏校准方法

1. 从正上方正确点触十字标记的中心
2. 依次点触右下和中间共3处，校准完成
3. 显示「校准完毕」后，确认4个十字是否正确点触
4. 确认后点触「确定」，如无法正确点触，点触「重试」再次进行

> 当出现无法正常点触的偏差时，按 `L + R + START` 键再按电源键，可直接进入触摸屏校准画面。

### 麦克风测试

向麦克风发出声音，确认音量条的颜色是否发生变化：
- 颜色变化 → 麦克风工作正常
- 颜色不变 → 麦克风可能故障

## 主机设置 4

| 选项 | 功能 |
|---|---|
| **主机更新** | 对 iQue DSi 菜单或主机内置软件进行功能添加或更新（需联网） |
| **主机初始化** | 将主机恢复到刚购买时的状态，删除所有添加到主机的软件和保存数据 |

### 主机初始化删除内容

- 从 iQue DSi 商店或 iQue DSi 专用软件购买添加的软件（已购的可从商店免费再次获取）
- 主机内置软件的各保存数据
- 初始设置和主机设置里的各项目

> **警告：一旦初始化，删除的数据就无法复原。**

## 键盘使用方法

输入文字时画面出现键盘，有普通键盘和数字键盘两种。

### 普通键盘输入模式

| 切换键 | 输入内容 |
|---|---|
| A 字母数字 | 英文字母和数字 |
| A 欧洲文字及特殊符号 | 欧洲字符 |
| 平假名/片假名 | 日文假名（平假/片假可切换） |
| 符号 / 图形符号 | 各种符号 |

### 主机按键操作键盘

| 按键 | 功能 |
|---|---|
| 十字键 | 光标移动 |
| A | 输入文字 |
| B | 删除最后输入的文字 |
| X | 平假名/片假名键盘切换 |
| Y | 字母数字键盘：变成按了 SHIFT 或 CAPS LOCK 后的状态 |
| L/R 键 | 键盘切换 |
| L+R 键 | 确认信息 |
| START | 发送信息 |
| SELECT（短按）| 复制信息 |
| SELECT（长按）| 删除信息 |
