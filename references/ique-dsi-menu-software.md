# iQue DSi 内置软件一览

开启 [[entities/ique-dsi|iQue DSi]] 后进入 **iQue DSi 菜单**，分为上屏幕（显示当前选中软件信息）和下屏幕（软件一览列表）。

## 菜单界面元素

| 元素 | 说明 |
|---|---|
| 用户名 | 左上角显示 |
| 日期/时间 | 上方显示 |
| 音量显示 | 左侧滑动条 |
| 电池电量 | 右上角 |
| 拍摄相片 | 上屏幕背景轮播 |
| 软件介绍 | 当前选中软件简介 |
| 开始光标 | 点触当前位置软件即启动 |

## 卡式软件图标

| 状态 | 图标 |
|---|---|
| 无游戏卡时 | 显示空白卡槽图标 |
| 插入游戏卡后 | 显示该游戏图标，左角显示"NEW"超级力欢兄弟 |

## 其他图标

| 图标 | 说明 |
|---|---|
| 剩余盒子图标 | 未装入软件的占位图标，数量与软件数量相同 |
| 礼盒图标 | 从 iQue DSi 商店购买软件操作后短暂显示，点触变为正式图标 |

## 软件位置移动方法

1. 点触并向上滑动想要移动的软件
2. 滚动软件一览，直至目标位置
3. 点触软件，滑动至目标位置
4. 松开完成移动

## 照相机快捷键

在 iQue DSi 菜单中，按 `[内] 或 [外]` 键可直接切换至照相机模式（拍摄的相片存入主机内存）。
