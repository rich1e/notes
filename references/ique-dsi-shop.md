# iQue DSi 商店与 iQue 点数

[[entities/ique-dsi|iQue DSi]] 内置商店，可在线购买 iQue DSi 专用软件等商品，使用 **iQue DSi 点数**（虚拟货币）支付。

## 使用前提条件

- **宽带互联网环境**（[[skills/ique-dsi-wifi-setup|Wi-Fi 设置]]）
- **iQue DSi 点数**（需先充值）
- 使用前需在 iQue DSi 上进行互联网设置并同意使用协议

## 什么是 iQue DSi 点数

在 iQue DSi 商店里购买 iQue DSi 专用软件等商品时，用来代替现金支付的点数。

将 **iQue 产品销售点**出售的「iQue 点卡（1000点）」登录到 iQue DSi 主机后，就能作为 iQue DSi 点数使用。

## iQue 点卡充值步骤

1. 在 iQue 产品销售点购买「iQue 点卡（1000点）」
2. 确认 iQue 点卡背面的密码条进行确认
3. 启动 iQue DSi 商店
4. 根据画面指示，输入 iQue 点数密码

## iQue 点卡使用限制

| 限制项 | 说明 |
|---|---|
| 地区限制 | 面向中国国内发售的点卡只能用于面向中国国内发售的 iQue DSi 主机 |
| 充值上限 | 点数超过 10000 点时，无法再次充值 |
| 无法分次充值 | 无法分次充值点卡里的点数 |
| 不可退款 | 无论任何情况，都不会对本点卡再次发行、查询、补充等措施 |
| 不可转让 | 点卡和已充值的 iQue DSi 点数无法退款、变卖、转让，以及转移到其他 iQue DSi 主机上 |
| 软件绑定 | 使用 iQue DSi 点数购买的软件无法退款、变卖、转让、转移到其他 iQue DSi 主机上 |
| 不可跨机 | 已充值的 iQue DSi 点数无法充值到其他 iQue DSi 主机 |

## 「购买」的含义

iQue DSi 专用软件等的「购买」代表 iQue 允许客户进行使用。详情请查看主机设置里的使用协议。

## 亲子管理与点数

监护人可通过设置[[skills/ique-dsi-parental-control|亲子管理]]，对 iQue DSi 点数的使用进行限制（无法购买）。
