## Supercard DSTwo plugins

### Information

A DSTwo 'Plugin' consists of 3 files stored in the '/_dstwoplug/' folder on the DSTwo flashcard
- A picture (16bit BMP 40x42 pixels in size)

- A ini file (contains 3 lines of info: 2 are used for 'Display Name' & Icon graphic location/name)

- A Homebrew *.nds file (or *.plg - a program specially developed to use the extra CPU/Memory of the DS2)



This Wiki contains a selection of 'unofficial' plugins found @ this post , where you will also find
- A Full download pack maintained by alidsl, containing virtually all Plugins shown here ( UPDATE 10/29/13 : Link is invalid on filetrip and on the official supercard forums!

- An alternative icon download pack made by VatoLoco

- Icon Templates for Slot-1 and Slot-2 , along with a 16-bit converting Tool that allows you to make your own compatible 'plugins' graphics



Official DSTWO plugins can be found here: http://eng.supercard.sc/manual/dstwo/plugin.htm 
To request or add an unofficial plugin visit this thread 

### How to add a Plugin

- Click on a 'Plugin' link to download the plugin file

- Unzip it & copy the BMP icon and INI file into the '/_dstwoplug/' folder on your DSTwo microSD memory card

- Click on the accompanying 'Program' link for the program file(s)

- Unzip & place the NDS file also into the '/_dstwoplug/' folder

- Make sure that the NDS file has the same name as the INI file - if the file is named differently, rename it

Note that some homebrew may need extra folders/files stored in specific area(s) on the flashcard.
You may need to read any accompanying 'readme.txt' files that come with the program for further information on setting those programs up.


### Common Plugin Problems



No 'INI' 

This means that the 'ini' file is either missing or is NOT named the same as the 'nds' file

NOT 16bit 

This means that the 'bmp' has not been saved/converted into a 16-bit colour depth graphic

No 'BMP' 

This means the 'bmp' is either missing or is NOT named the same as in the 'ini' file
